# JS Green Iron Ore

[![Modrinth](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/available/modrinth_vector.svg)](https://modrinth.com/project/5MAxfr8R)

A simple texture pack that turns the normal and deepslate iron ore Block completely green. No other changes made. Perfect for much better visibility and compatible with all Minecraft versions.
